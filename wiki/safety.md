> 生物安全、化学安全、实验室安全、当地法规合规问题。本文档会随项目进展动态更新。

## 1. Project Overview

**项目名称**: BrewXOS — 让百万吨啤酒废料（BSG）变身守护肠道的黄金益生元

**项目目标**: 通过合成生物学方法，将啤酒工业副产物（brewer's spent grain, BSG）
转化为高附加值的木寡糖（xylo-oligosaccharides, XOS）益生元，服务肠道健康产业。

**核心合成生物学路径**:

```
BSG 预处理（物理/化学）
   ↓
木聚糖（xylan）提取
   ↓
木聚糖酶水解  ──OR──  工程菌直接发酵
（Bacillus subtilis WB800 分泌 xylanase）   （一锅法）
   ↓
XOS 分离 + 纯化
   ↓
食品级益生元（GRAS）
```

**目标产物**: XOS（木寡糖）— 一种公认安全的益生元（prebiotic），不涉及活菌。

## 2. Organisms Used

### 2.1 工程菌 / 表达宿主

| 菌株                              | 来源                  | 风险组          | GRAS 状态 | 用途                                            |
| ---------------------------------- | --------------------- | --------------- | --------- | ----------------------------------------------- |
| **Bacillus subtilis WB800**        | 商业 / 实验室保藏     | **Risk Group 1** | **GRAS**  | 表达分泌型木聚糖酶（xylanase）                 |
| **Escherichia coli BL21(DE3)**     | 商业 / 实验室保藏     | **Risk Group 1** | —         | Pre-iGEM Training：表达 NMN 合成酶（已完成）  |
| **E. coli DH5α**（克隆用）         | 商业 / 实验室保藏     | **Risk Group 1** | —         | 质粒构建与扩增                                  |

### 2.2 安全性说明

- **所有菌株均为 Risk Group 1**（最低风险组）。
- 按中国《病原微生物实验室生物安全管理条例》（国务院第 424 号令），**本项目不涉及
  第二类、第三类、第四类病原微生物**。
- **Bacillus subtilis** 已被 **FDA**（美国食品药品监督管理局）、**EFSA**（欧洲食品
  安全局）、**中国国家卫健委** 列入 **GRAS（Generally Recognized as Safe）名单**，
  长期用于食品发酵（纳豆、酱油、味噌等传统食品）。
- **WB800** 株是 B. subtilis 168 的蛋白酶缺陷株（ΔaprE, ΔnprE, Δepr, Δbpr, Δmpr,
  ΔnprB, Δvpr, ΔwprA），**已敲除 8 个胞外蛋白酶**，便于重组蛋白分泌表达；该改造
  仅影响蛋白酶活性，**不引入任何致病性增强或毒素基因**。

### 2.3 工程改造方式

- **插入/过表达**：xylanase 编码基因（来自 Bacillus 或真菌，已公开序列）
- **可能的通路优化**：BSG 降解相关糖苷酶
- **筛选标记**：标准营养缺陷型筛选（如 trp-, leu-）或特定抗生素抗性（仅在分子
  克隆阶段使用，最终菌株不携带抗生素抗性基因用于发酵）
- **不引入**：毒素基因、致病性基因、过敏原基因、抗生素抗性传播元件

## 3. Laboratory Information

### 3.1 实验室与硬件

- **实验室类型**: **BSL-1**（基础生物安全一级实验室）
- **硬件平台**:
  - **DFRduino Mega2560**（Arduino Mega 2560 兼容，DFRobot 定制）
  - 4 路传感器：pH、溶解氧（DO）、CO₂（SCD4X）、温度（DS18B20）
  - 加热膜 + 半导体制冷片（TEC）温控系统
  - 蠕动泵（pH 调节 + 取样）
  - LCD 显示屏（实时数据可视化）
- **发酵罐**: 自制小型智能发酵系统，3D 打印 L 形外壳（PLA / PETG，约 45 cm）
- **培养条件**: 30-37°C（最适 37°C，匹配 B. subtilis WB800）

### 3.2 安全设备

| 类别       | 设备                                              |
| ---------- | ------------------------------------------------- |
| 个人防护   | 实验服、一次性丁腈手套、护目镜                  |
| 消毒       | 75% 乙醇、紫外灯（30 min 照射）                  |
| 灭菌       | 高压蒸汽灭菌锅（121°C，20 min）                  |
| 培养       | 30/37°C 恒温培养箱、恒温摇床                    |
| 应急       | 淋浴洗眼器、ABC 干粉灭火器、急救箱              |
| 废弃物     | 生物废弃物专用袋（121°C 灭菌后按医疗废物处理）  |

### 3.3 应急程序

| 情况       | 处置                                                    |
| ---------- | ------------------------------------------------------- |
| 菌液溅洒   | 75% 乙醇覆盖 → 紫外 30 min → 报告实验室管理员         |
| 皮肤接触   | 立即用流水冲洗 15 min                                  |
| 眼睛溅入   | 洗眼器冲洗 15 min → 校医务室                           |
| 火灾       | ABC 干粉灭火器 → 疏散 → 拨打 119                       |
| 培养物污染 | 121°C 高压灭菌 30 min 后再处理                         |

## 4. Biosafety Assessment（生物安全评估）

### 4.1 工程菌环境释放风险：**低**

- 释放场景：实验废液 → 学校下水道 → 城市污水处理厂
- **B. subtilis** 在土壤、水体、植物表面**天然存在**（常见于食物和环境中）
- 工程改造**未引入任何致病性增强**（仅敲除蛋白酶 + 插入 xylanase 表达盒）
- 灭菌后释放（121°C 高压灭菌 20 min 后所有细胞死亡）

### 4.2 食品应用安全

- **目标产物 XOS 不是活菌**，是经纯化后的寡糖分子
- **XOS 已被中国卫健委列入食品添加剂名单**（类似低聚果糖 FOS）
- **GRAS 状态**：在欧美及日本广泛作为益生元食品添加剂
- **本项目阶段**：仅**实验室规模**验证（1-10 L 发酵），**无商业化生产**

### 4.3 人体与动物实验：**无**

- ❌ **不涉及人体实验**（no human subjects research）
- ❌ **不涉及动物实验**（no animal testing）
- ✅ 仅做**体外酶活实验 + 体外发酵实验**（in vitro）
- ✅ XOS 的健康功效基于已发表文献支持（不用本项目重复人体实验）

### 4.4 Dual Use Research of Concern (DURC)：**无**

- 项目**无任何武器化潜力**
- **不涉及**：毒素、致病性增强、抗生素抗性传播、生物武器相关
- 项目目标明确为**食品/健康产业应用**

## 6. Project-Specific Concerns（项目特定风险）

### 6.1 食品级安全（Food-grade Safety）

- XOS 终产物用于**食品/保健品添加剂**
- 食品安全法规遵循：
  - 《中华人民共和国食品安全法》
  - GB 2760《食品添加剂使用标准》
  - GB 14880《食品营养强化剂使用卫生标准》
- **本项目仅做**实验室概念验证（proof-of-concept），**不进入商业化生产**

### 6.2 益生菌 / 益生元区分

- **XOS 是益生元（prebiotic）**，不是益生菌（probiotic）
- 益生元 = 肠道有益菌的"食物"（不被人体消化，但能促进益生菌生长）
- **不直接引入活菌**到人体或环境，避免了益生菌安全性争议

### 6.3 数据安全

- 所有实验数据保存在**学校服务器 + 个人加密硬盘**
- **不涉及人类基因数据**（无 human subjects）
- **不涉及敏感生物信息**（BSG 是工业废料，无伦理问题）

### 6.4 知识产权

- 使用菌株均为**商业可获得**或**学术公开**资源
- 酶基因序列来自公共数据库（NCBI, UniProt）
- **不涉及专利侵权**（已 review 主要文献）

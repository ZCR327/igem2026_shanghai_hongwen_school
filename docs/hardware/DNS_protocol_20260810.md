## 1. DNS 试剂配方（Miller 1959 改良法）

### 试剂成分（500 mL 体系）

| 成分 | 用量 | 作用 |
|---|---|---|
| 3,5-二硝基水杨酸 (DNS) | 5.0 g | 显色剂（还原糖 → 棕红色） |
| 氢氧化钠 (NaOH) | 5.0 g | 碱性环境 |
| 酒石酸钾钠四水合物 | 100 g | 络合剂，防氧化 |
| 苯酚 (重蒸) | 1.0 mL | 增敏（可选） |
| 亚硫酸钠 (Na₂SO₃) | 0.25 g | 稳定剂 |
| 蒸馏水 | 定容到 500 mL | 溶剂 |

### 配制步骤

1. 称 5.0 g NaOH 溶于 ~200 mL 温水（40-50°C）
2. 加入 5.0 g DNS，搅拌至完全溶解（溶液变黄）
3. 加入 100 g 酒石酸钾钠，搅拌溶解
4. 加入 0.25 g 亚硫酸钠
5. 加入 1.0 mL 苯酚（重蒸）
6. 冷却到室温后，蒸馏水定容到 500 mL
7. 棕色瓶避光保存，**4°C 冰箱**，稳定期 ~6 个月
8. ⚠️ **使用前回温到室温 + 摇匀**

### 安全提示
- DNS 是强氧化剂 + 有毒，避免皮肤接触
- NaOH 强碱，配制时戴手套 + 护目镜
- 操作在通风橱内

## 2. 木糖标准曲线（Xylose Standard Curve）

### 储液 (Stock, 1 mg/mL)
- 称 0.100 g 木糖 (D-Xylose, AR 级) 溶于 100 mL 蒸馏水
- 4°C 冰箱保存，**1 周内用完**

### 标准梯度（6 管）

| 编号 | 木糖终浓度 (mg/mL) | 取储液 (mL) | 蒸馏水 (mL) |
|---|---|---|---|
| S0 | 0.0 | 0.0 | 1.0 |
| S1 | 0.2 | 0.2 | 0.8 |
| S2 | 0.4 | 0.4 | 0.6 |
| S3 | 0.6 | 0.6 | 0.4 |
| S4 | 0.8 | 0.8 | 0.2 |
| S5 | 1.0 | 1.0 | 0.0 |

### 显色反应（每管）
1. 取 1.0 mL 木糖标准液 + 1.0 mL DNS 试剂，混匀
2. **沸水浴 5 min**（精确计时）
3. 冷水冷却到室温
4. 加 8.0 mL 蒸馏水稀释（终体积 10 mL）
5. 摇匀，**A540 nm 测吸光度**

### 标曲绘制
- X 轴：木糖浓度 (mg/mL)
- Y 轴：A540
- 线性回归得：y = kx + b
- **R² ≥ 0.999 才算合格**（重配 S 梯度重测）

### 样品测定
- 取 1.0 mL 适当稀释的酶水解上清液
- 同上步骤 1-5
- 代入标曲公式反算 XOS / 木糖浓度
- 乘以稀释倍数 = 实际浓度
